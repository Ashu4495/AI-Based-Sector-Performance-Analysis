# SectorAI Frontend

Custom React dashboard built with Vite, Tailwind CSS, Recharts, and Lucide icons for NSE Sector Performance & Health Classification.

## Design Highlights
- Dark (analyst "trading desk" feel) and Light mode support with curated palette from `design.md`
- Fraunces serif display, IBM Plex Sans body, IBM Plex Mono tabular numbers
- Continuous dynamic ticker strip
- SHAP feature explainability cards
- Backtest equity curve vs. NIFTY 50

## Running
```bash
npm run dev
```
